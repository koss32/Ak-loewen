# Release 4 — AK LÖWEN

## Что это

**Release 4 — следующая версия проекта AK LÖWEN.** Она продолжает то же приложение (лендинг + Telegram-интеграция) и сосредоточена на лендинге: разделение фактического и юридического адреса, присутствие двух брендов и вход в Telegram.

Release 3 остаётся базовой веткой разработки: изменения Release 4 приходят в `release-3` через PR.

## Статус

**WIP / Preview. Production не деплоится без отдельного решения владельца.**

## Что сделано

1. **Standort / адрес.** В блоке рядом с `Werwolf 8, 42651 Solingen` остался только фактический адрес тренировок, действие открытия карты, короткая заметка и ссылка на `/<locale>/impressum/`. Geschäftsführer, юридический адрес, Amtsgericht и HRB остались только на Impressum. Новые юридические данные не выдумывались.
2. **Контактные карточки (`Zwei Bereiche. Direkt in Kontakt.`).** AK Löwen получил `/assets/ak-logo.png`, VALSET — оригинальную `/assets/valset.jpg`. Тёмная стилистика и баланс карточек сохранены.
3. **Объединение AK Löwen + VALSET.** Вместо одного знака — композиция из двух брендовых элементов, которые сходятся навстречу к общему шву. Анимация scroll-driven (`animation-timeline: view()`) с fallback-анимацией при загрузке, статичным конечным состоянием по умолчанию и полным `prefers-reduced-motion: reduce` fallback. Мобильные размеры на 800px и 540px.
4. **VALSET hero/card.** `figure.valset-art.is-full`: `aspect-ratio:auto`, `object-fit:contain`, внутренние отступы `clamp(16px, 2.4vw, 30px)`. Обрезки сверху нет, asset не заменён.
5. **Telegram CTA.** Широкий блок заменён на компактную кнопку `.telegram-cta`: в покое виден значок Telegram, при hover/focus она разворачивается и показывает локализованный текст. Полный текст в `aria-label`/`title`, на touch и coarse-pointer кнопка всегда развёрнута, при `prefers-reduced-motion` переходы отключены.
6. **Текст Sambo & MMA.** По решению владельца описание переписано: коротко, без истории, акцент на прикладную самооборону и на причины записаться (с нуля, работа в паре под контролем тренера, DE/RU/UK/TR, пробное занятие без экипировки). Никакие цены, звания или гарантии не добавлялись.

## Файлы

- `site/src/render-final.js` — все правки разметки через анкерные замены `patch()`; отсутствующий или неуникальный анкер — жёсткая ошибка, а не тихая потеря правки.
- `site/src/brand-union-copy.js` — копирайт DE/RU/UK/TR для Standort-заметки, подписи объединения и Telegram-кнопки.
- `site/src/brand-union-styles.js` — стили правок; инжектируются в `<head>` вместе с существующими стилями render-final, поэтому работают и в standalone-сборке.
- `site/tests/brand-union.test.js` — regression-тесты по всем пунктам и локализациям.
